# Полный справочник голосовых команд

Назовите имя бота отдельно, дождитесь сигнала, затем произнесите одну команду. Имя показывает /voice status. Управление доступно участникам голосового канала бота.

В шаблонах «/» разделяет варианты, «+» соединяет слова через пробел, [квадратные скобки] означают необязательную часть. Все сочетания разрешены внутри указанного шаблона. Ниже перечислены все шаблоны команд и дополнительные точные фразы; свободные названия песен описаны отдельно.

Перед командой допускаются до трёх вводных слов «бот / bot / вот / ну / пожалуйста / слушай / давай»; после команд управления — «пожалуйста / please». Регистр, «ё/е» и обычная пунктуация не важны. Вопросы, отрицания и несколько действий в одной фразе не исполняются. В полном профиле команды плеера дополнительно проходят проверку модели; качество распознавания речи влияет на результат.

«Включи песню …» оставляет следующие слова названием для поиска, даже если название совпадает с командой.

## Включение радио

«включи / включить / включай / ключи / ключить / поставь / поставить / запусти / запустить / хочу послушать / послушаем» + название станции. Можно предварить просьбой «можешь / можете», либо назвать станцию отдельно после сигнала.

Станции: Европа Плюс, Ретро FM, Дорожное радио, Русское радио, Авторадио, DFM, Радио ENERGY, Love Radio, Радио Дача, Наше радио, Хит FM.

Примеры: «включи Европа Плюс», «поставь радио Дача», «хочу послушать Авторадио». Когда играет радио, «выключи радио» и «останови радио» останавливают эфир и отключают бота.
