# muz-bot-ds

Discord-бот для воспроизведения YouTube и YouTube Music. Поиск, метаданные и аудио обрабатывает `yt-dlp`; звук кодируется FFmpeg и передаётся через `@discordjs/voice` с поддержкой DAVE.

## Требования

- Node.js 24.17+ и npm.
- Python 3.11+ с `venv` и `pip` на Windows или Linux.
- Доступ к PyPI при первом запуске: бот создаёт `.runtime/yt-dlp` и устанавливает `yt-dlp[default]` вместе с EJS. Последующие запуски не обновляют пакет автоматически.
- FFmpeg с `libopus`. `ffmpeg-static` устанавливает его через npm; при необходимости задайте `FFMPEG_PATH`.

Для Windows не нужны Visual Studio или нативный `@discordjs/opus`: используется `opusscript`.

## Установка и запуск

```bash
npm install
cp .env.example .env
npm run build
npm run deploy
npm start
```

На Windows вместо `cp` используйте `Copy-Item .env.example .env`. Укажите в `.env` `DISCORD_TOKEN` и `CLIENT_ID`. Необязательный `GUILD_ID` регистрирует команды сразу на тестовом сервере; без него команды регистрируются глобально. После изменения описания слэш-команд снова запустите `npm run deploy`.

`npm run dev` запускает исходники TypeScript в режиме наблюдения. `npm run update:ytdlp` обновляет управляемую установку `yt-dlp`. При использовании `YT_DLP_PATH` бот проверяет внешний исполняемый файл, но его обновление остаётся за администратором.

## Команды

| Команда | Действие |
| --- | --- |
| `/play <query> [infinite]` | Добавить видео, поиск или плейлист. Без `infinite` из плейлиста берётся первый трек; с ним — до 25. |
| `/skip`, `/stop`, `/pause`, `/resume` | Управлять воспроизведением. |
| `/clear`, `/volume <1-150>`, `/autoplay` | Управлять очередью, громкостью и рекомендациями. |
| `/queue [page]`, `/nowplaying` | Посмотреть состояние. |
| `/player` | Показать публичный плеер с кнопками. |
| `/watch` | Создать приглашение в Watch Together. |
| `/voice on`, `/voice off`, `/voice status` | Включить, отключить или проверить голосовое управление. |
| `/voice name [value]` | Сохранить новое обращение на этом сервере; без `value` — вернуть имя Discord. |

Если ссылка из «Понравившейся музыки» содержит `v=`, `/play` воспроизводит это видео как обычный трек. Ссылка только с `list=LM` не содержит ID песни; для неё укажите ссылку на конкретную песню или её название.

Команды и кнопки, меняющие воспроизведение, доступны участникам того же голосового канала, что и бот. Ответы команд приватные, кроме публичного сообщения `/player` и его автоматического обновления. Бот выходит из голосового канала через пять минут после окончания очереди.

## Голосовое управление

Подготовьте локальные модели командой `npm run setup:voice`, затем выполните `npm run deploy` и запустите бота. Установка требует Python 3.11+, доступа к PyPI, PyTorch и Hugging Face, места для зависимостей и моделей. Окружение, веса и закреплённый список установленных зависимостей находятся в `.runtime/voice`. Whisper `small` работает через faster-whisper на CPU в INT8, Laya Multilingual выбирает действие по русскому тексту. Модели загружаются один раз в постоянный процесс; после подготовки обработка работает без облачного API. Повторная `setup:voice` переустанавливает закреплённые зависимости и проверяет модели; обновления при обычном запуске не скачиваются.

После подключения бот автоматически слушает обращение по своему серверному нику, либо имени аккаунта. Имя произносится отдельной фразой: **«Муза» → дождаться сигнала → «Следующий трек»**. Нужное обращение показывает `/voice status`. Чтобы изменить его, используйте `/voice name value:Джев`; имя сохраняется отдельно для каждого сервера и переживает перезапуск. `/voice name` без значения сбрасывает настройку. Менять её и включать/выключать прослушивание может участник канала бота.

После сигнала музыка становится на 80% тише. У назвавшего имя человека есть 10 секунд на начало команды; речь завершается после 800 мс тишины, максимальная длительность — 15 секунд. Другие участники не могут перехватить команду. После выполнения, молчания или ошибки приглушение снимается. Изменённая громкость сохраняется; пауза и остановка остаются в силе. На время самого короткого сигнала музыкальный ресурс приостанавливается и затем продолжается с прежнего места.

Доступны «следующий трек», «пауза», «продолжи музыку», «останови музыку» (с выходом из канала), «громкость пятьдесят процентов», «сделай громче» и «сделай тише». Относительное изменение — 10 процентных пунктов, диапазон — 1–150%. За одно обращение принимается одно действие. Поиск и добавление песен, отрицательные, составные и непонятные просьбы не выполняются. Название и произношение обращения должны совпадать с результатом распознавания: нечётких совпадений нет.

Для отслеживания имени речь участников обрабатывается локально ещё до сигнала. Аудио и расшифровки находятся в памяти, не сохраняются и не выводятся в обычные логи. `/voice off` выключает приём до следующего подключения; новое подключение вновь включает его автоматически. Если модели не подготовлены или обработчик остановлен, музыкальные команды продолжают работать; восстановить прослушивание можно через `/voice on`.

Качество Whisper и Laya зависит от голоса, шума и формулировок. Порог уверенности служит фильтром, а не гарантией точности. Перед использованием проверьте своё имя и команды в тестовом голосовом канале.

## Проверка

`npm test` запускает автономные тесты и сборку. `npm run test:integration` отдельно проверяет YouTube, получение аудио и рекомендации; для него нужны сеть, Python, yt-dlp и FFmpeg. Для окончательной проверки запустите бота на тестовом сервере и проверьте `/play`, `/player`, кнопки, пропуск и повторное подключение.

`npm run test:voice` отдельно проверяет настоящую Laya на русских командах и неподдерживаемых просьбах, печатает число правильных ответов и задержку. Для проверки Whisper задайте `VOICE_TEST_FIXTURES` — путь к локальному JSON-манифесту, например `[{"file":"wake.wav","wakeName":"Муза"},{"file":"next.wav","action":"skip"}]`. WAV-пути разрешаются относительно манифеста; звук декодируется FFmpeg в памяти, расшифровки не печатаются. Синтезированная речь проверяет работоспособность цепочки, но не заменяет проверку настоящих голосов в Discord.

## Настройки

| Переменная | Назначение |
| --- | --- |
| `DISCORD_TOKEN` | Токен бота. |
| `CLIENT_ID` | ID приложения. |
| `GUILD_ID` | Сервер для мгновенной регистрации команд. |
| `YT_DLP_PATH` | Внешний yt-dlp вместо управляемого Python-окружения. |
| `FFMPEG_PATH` | Внешний FFmpeg вместо `ffmpeg-static`. |
| `WATCH_TOGETHER_APP_ID` | ID активности Watch Together. |
| `WHISPER_MODEL` | Модель Whisper при `setup:voice`; по умолчанию `small`, нужна многоязычная версия. |
| `VOICE_CPU_THREADS` | Число потоков CPU для локальных моделей, по умолчанию 4, максимум 8. |
| `VOICE_TEST_FIXTURES` | Манифест локальных аудиопримеров для `test:voice`. |

Боту нужны Gateway Intents `Guilds` и `GuildVoiceStates`, а также права `Connect`, `Speak`, `Send Messages` и `Embed Links`. Для `/watch` дополнительно нужны `Create Invite` и `Use Activities`.
