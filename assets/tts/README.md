# Короткие голосовые ответы

Готовые записи соответствуют `src/voice/confirmations.json`; `ready.json` содержит проверяемый манифест. Формат: gzip со стерео PCM s16le, 48 кГц. Воспроизведение не требует Python, движка TTS или интернета. Полный набор занимает около 2,3 МиБ на диске и 4,2 МиБ после распаковки.

Записи синтезированы Silero v5.5, голосом `xenia`, из фиксированных фраз бота. Нормализация и форматирование выполнены `scripts/setup_silero_tts.py` (−18 LUFS, −6 dBTP). Личные записи и речь пользователей здесь не используются.

Для изменения фраз подготовьте окружение с PyTorch (`VOICE_PROFILE=heavy`), задайте `VOICE_TTS_ENGINE=silero` и выполните `npm run setup:tts`. Обновите gzip-копии полученных `.runtime/tts/*.pcm` и манифест bundled вместе с исходным JSON. `VOICE_TTS_ENGINE=piper` также доступен для собственного кэша. Без обновления записей режим bundled отклонит изменённые фразы.
