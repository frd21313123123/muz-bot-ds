# Короткие голосовые ответы

Готовые записи соответствуют `src/voice/confirmations.json`; `ready.json` содержит проверяемый манифест. Формат: gzip со стерео PCM s16le, 48 кГц. Воспроизведение не требует Python, движка TTS или интернета. Полный набор занимает около 2,3 МиБ на диске и 4,2 МиБ после распаковки.

Записи сгенерированы через ElevenLabs (голос `Artspace`), из фиксированных фраз бота. Нормализация, обрезка тишины и форматирование выполнены `scripts/import_sounds.js` (−18 LUFS, −6 dBTP). Личные записи и речь пользователей здесь не используются.

Для обновления фраз положите аудиофайлы в папку `sounds/` и выполните `node scripts/import_sounds.js`. Скрипт автоматически обрежет тишину, выполнит нормализацию громкости, упакует файлы в gzip стерео PCM 48 кГц и обновит манифест `ready.json`.
